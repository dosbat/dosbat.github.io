5. 调整 Swap 使用策略

默认 vm.swappiness=60，意味着内存用到 60% 就开始换页。服务器上通常希望优先用物理内存，内存不足了再 swap，所以调低：

参数说明

  • vm.swappiness=10：降低换页倾向。设成 0 会完全禁用 swap，内存紧张时进程直接被 OOM Kill，反而更危险。
  • vm.vfs_cache_pressure=50：默认 100 表示缓存回收积极。调低可让 inode/dentry 缓存保留更久，减少频繁的磁盘 IO。

总结

一台服务器从裸机到能跑生产服务，完整链路是：

磁盘分区 → Swap → 系统更新 → 时区 → Docker → 用户与权限 → SSH 加固 → 容器化部署 → 安全检查

每个环节都有对应的坑：

环节 关键点
Swap 权限必须 600；vm.swappiness 调低到 10
磁盘 fdisk 交互要点；用 UUID 挂载；先 mkfs 再挂载
Docker 必须限制日志大小；国内建议配镜像加速
用户 用组统一授权 sudo；visudo 避免语法错误
SSH 先验证新端口再关旧窗口；改端口前先放行防火墙
Nginx 用 fullchain.pem 而非 cert.pem；配置改完先 nginx -t

把这套流程固化下来，之后每上一台新机器，半小时内就能完成基础环境搭建，业务部署就是后面的事了。
