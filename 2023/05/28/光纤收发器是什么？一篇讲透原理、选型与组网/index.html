光纤收发器是什么？一篇讲透原理、选型与组网

发表于2023-05-28|更新于2026-11-22|网络技术硬件基础
|字数总计:2.3k|阅读时长:7分钟|阅读量:

做弱电、盯机房，迟早会碰到一个巴掌大的小铁盒——一头插网线，一头插光纤，中间亮着几个绿灯。它就是光纤收发器，也叫光电转换器。

别看它不起眼，两栋楼之间的监控、园区网的远距离互联、电梯和车库的接入，几乎都靠它打通。这篇把它讲透：它到底干了什么、怎么分类、怎么选、接线怎么接、不通了怎么查。

一、它到底是干什么的

一句话：把网线的电信号和光纤的光信号互相转换，让以太网能传得更远。

网线（双绞线）有个硬伤——有效传输距离只有 100 米。超过这个长度，信号衰减、丢包、协商速率掉下来，再长干脆不通。而光纤轻松传几公里到几十公里。

光纤收发器就是接在中间的翻译官：

  • 发送端：把交换机出来的电信号转成光信号，送进光纤
  • 接收端：把光纤里的光信号还原成电信号，交给对端交换机

对两端的设备来说，它完全透明——就像一根超长的网线。交换机不知道中间隔了光纤，配置不用改任何东西。

为什么不用交换机上的光口

有人会问：现在交换机不都有 SFP 光口吗，插个光模块不就行了？

确实，核心交换机走光口是主流。但光纤收发器有它不可替代的场景：

场景 用收发器 用光模块
老设备只有电口 ✅ 加个收发器就能接光纤 ❌ 没有光口插不了
远距离单条链路 ✅ 成对即用，不用动交换机 需要交换机有空余光口
现场/柜内远端接入 ✅ 导轨式，就近安装供电 光模块在交换机侧，远端还是要布线
成本敏感的点位 ✅ 一对几百块搞定 光模块 + 带光口交换机成本高

简单说：光模块是”给设备加光口”，收发器是”给链路加光纤段”。很多现场是两者配合用的。

二、工作原理：六步走完一次转换

拆开看，一台收发器的核心就三块：RJ45 电口 → PHY 处理芯片 → 光模块。信号走一遍是这样的：

1. 电信号进入
交换机的 RJ45 口送出差分电信号，通过网线进入收发器的电口。

2. PHY 芯片处理
PHY（物理层芯片）负责信号的编码解码、时钟恢复，把以太网帧整理干净。

3. 电转光（E/O）
芯片驱动光模块里的激光二极管（单模）或 LED/VCSEL（多模）发光，电信号被调制成光脉冲。

4. 光纤传输
光脉冲在光纤里靠全反射向前传播，衰减小、不受电磁干扰——这是光纤比网线强的根本原因。

5. 光转电（O/E）
对端收发器的光电二极管接收到光信号，还原成电信号。

6. 送回以太网
对端 PHY 再处理一遍，从 RJ45 口送进交换机。整个过程是双向的，收和发同时跑。

TX 与 RX 的坑：双纤收发器有两个光口，标 TX（发）和 RX（收）。一端 TX 必须接对端 RX，交叉对应。接反了灯不亮、链路不通，把两根纤对调一下就好——这是新手最常踩的坑。

三、两个维度看懂分类

市面上的收发器名字五花八门：单模、多模、单纤、双纤、百兆、千兆……其实就两个独立维度，交叉组合。

维度一：单模还是多模

按光纤的芯径分：

  • 多模（MMF）：芯径 50/62.5μm，光走多条路径、散射传播，距离短（2km 内），跳线常是橙色或水绿色，波长 850nm
  • 单模（SMF）：芯径 9μm，光几乎直线传播，距离远（20~120km），跳线是黄色，波长 1310/1550nm

一句话记：近距离、省钱用多模；远距离、主流用单模。实际工程里单模用得最多。

维度二：单纤还是双纤

按用几根光纤分：

  • 双纤：一根发（TX）、一根收（RX），交叉连接，最稳定、最常见
  • 单纤（BIDI）：用 WDM 波分复用技术，一根纤上跑两个波长（一端 1310nm 发、另一端 1550nm 发），双向传输，省一半光纤

单纤的坑：单纤收发器分 A 端和 B 端，必须成对买、波长互补。买两个 A 端是通不了的——采购时一定要跟卖家说清楚一端 A、一端 B。

还有两个常见说法

  • 百兆 / 千兆 / 万兆：指速率，要和两端设备端口速率匹配，现在主流是千兆
  • 机架式 / 导轨式 / 桌面式：指安装形态，机柜集中用机架式（14 槽卡式），现场柜内用导轨式

四、选型四步法

把上面的维度串起来，照着走不会错：

第一步，定距离选单多模。 2km 内多模，2~20km 单模，超过 20km 上单模长距模块（40/80/120km）。

第二步，定速率。 百兆/千兆/万兆，跟两端端口一致。注意有些收发器电口是千兆、光口是百兆，买前看清参数。

第三步，数光纤根数。 有两根纤用双纤，只剩一根用单纤 BIDI。同时确认接口类型（SC/FC/LC）对得上。

第四步，定安装形态。 机柜集中管理用机架式，现场柜内用导轨式，临时用桌面式。别忘了确认供电——有 220V 交流的，也有 5V/12V 直流的，柜内通常用于后者。

长距模块的反向坑：40km 以上的模块发射功率大，如果只传 500 米，光功率过强会”晃瞎”对端接收器，反而丢包。这种情况要加光衰减器。短距离别盲目上长距模块。

五、典型组网：连接两个远距离机房

最常见的用法是这样：

机房 A 的核心交换机，用网线连到收发器 A；收发器 A 通过光纤（可能几公里、几十公里）连到远端机房的收发器 B；收发器 B 再用网线接前端的接入交换机或摄像头。

典型场景：

  • 监控跨楼布线：NVR 在中心机房，摄像头在另一栋楼
  • 园区网互联：办公楼到厂房、到仓库
  • 电梯/车库接入：弱电井到机房超过 100 米
  • 厂区远距离点位：配电房、水泵房等分散点位回传

接线检查清单：

  1. 两端收发器型号一致（同品牌、同速率、同波长）
  2. 单纤分 A/B 端，成对配对
  3. 双纤 TX↔RX 交叉连接
  4. 光接口清洁，无灰尘、无划痕（别用手摸陶瓷芯）
  5. 供电正常，PWR 灯亮
  6. 上电后看 LINK 灯：光口 LINK 亮说明光纤链路通，电口 LINK 亮说明网线通

六、不通了怎么查

收发器故障其实就那几类，按顺序查：

1. PWR 灯不亮 → 查电源。适配器坏了、供电电压不对、接触不良。

2. 光口 LINK 灯不亮（最常见）→ 按这个顺序排查：

  • 光纤接反了（双纤 TX/RX 对调）
  • 单模多模混用了（黄色纤配了多模模块）
  • 单纤 A/B 端买反了
  • 光模块型号不匹配（波长不一致）
  • 光纤断了 or 接头脏了（清洁接头、换根纤试）
  • 距离超了模块能力（加中继或换长距模块）

3. 光口 LINK 亮，但网络不通 → 问题多半不在光纤：

  • 网线问题（测线仪打一下，8 芯是否全通）
  • 两端端口速率/双工不匹配（强制千兆全双工试试）
  • IP 地址配置错误、VLAN 没放行
  • 收发器死机（断电重启，长期建议选带看门狗的工业级）

4. 时通时断、丢包 →

  • 光功率临界（距离太长、接头脏、光纤弯折过度）
  • 长距模块近距离用，光功率过强（加衰减器）
  • 供电不稳（尤其 12V 直流，电压跌落）
  • 设备过热（柜内温度高，工业级 -40~75℃ 的更稳）

一个实用技巧：判断是光纤段还是网线段的故障，用替换法最快——先把一对收发器放在桌上，用一根短光纤直连，两个电口接电脑互 ping。通了，说明收发器没问题，故障在中间的光纤链路（布线、接头、距离）；不通，就是收发器或配置的问题。这样一步就能把故障范围砍一半。

七、写在最后

光纤收发器是个”简单到没存在感，但出问题很要命”的设备。记住三条就够了：

  1. 它是对称的：成对使用、型号一致、供电正常，这是能通的前提。
  2. 光口 LINK 灯是分水岭：灯不亮查光纤（接反、混用、波长、距离），灯亮但不通查网线和数据配置。
  3. 采购前想清楚四件事：距离、速率、光纤根数、安装形态——这四项定了，型号基本就锁死了。

把这套逻辑记住，下次面对那个亮着绿灯的小铁盒，就不慌了。
