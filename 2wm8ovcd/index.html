综自与远动规约速查

发表于2026-11-15|更新于2026-11-15|弱电与电气智能化电力自动化与综自
|字数总计:3.5k|阅读时长:11分钟|阅读量:

一、一张表看清定位

规约 主要用途 传输方式 数据模型 国内对应标准
Modbus RTU / TCP 多功能电表、直流屏、温控器、UPS 等辅助设备采集 RS-485 或以太网（TCP 502），主从轮询 寄存器 / 线圈，扁平地址 事实标准，行业广泛使用
DL/T 645 电能表数据（电度、需量、费率） RS-485 串口 数据标识 DI（4 字节） DL/T 645-2007
IEC 60870-5-103 微机保护装置 ↔ 站控层/保护管理机 串口或光纤，问答式 功能类型 FUN + 信息序号 INF（ASDU） DL/T 667
IEC 60870-5-104 变电站 ↔ 调度主站远动通信 TCP/IP（默认端口 2404），平衡传输 101/103 的 ASDU 网络扩展，四遥 DL/T 634.5104
IEC 61850 智能变电站全站通信 以太网：MMS / GOOSE / SV 面向对象（LD / LN / DO / DA），SCL 自描述 DL/T 860

一句话记忆：简单采集 Modbus，电表 DL/T 645，保护接入 103，远动上送 104，新建智能站 61850。安全与实时性要求高的场合，别用轮询协议凑合。

二、按层记，不会混

智能变电站常说的「三层两网」是理解规约分布最好的骨架：

  • 设备层/辅助设备：多功能电表、直流屏、温控器、UPS → 多为 Modbus RTU/TCP 或 DL/T 645。
  • 间隔层 → 站控层：保护动作信号、故障录波、定值管理 → 103（存量站大量使用）。
  • 站 → 调度：遥测、遥信、遥控、遥调 → 104，国内调度主流。
  • 智能变电站全站：IED 互操作、GOOSE 快速跳闸、SV 采样值 → 61850，新建站趋势。

实际项目几乎都是混合组网：站控层 61850、调度侧 104、辅助设备 Modbus，中间靠通信管理机/远动机做规约转换。改造站尤其明显 —— 老装置只有 103 或厂家私有规约，电表走 645，直流屏走 Modbus。通信管理机的串口/网口数量必须按现场实际点表配，不能只按新设备的规约配，否则投运时才发现少两个 485 口。

三、IEC 60870-5-104：调试时真正要看的细节

104 是把 101 的应用层搬到 TCP/IP 上，物理链路排障和报文排障是两回事。

帧结构与链路建立

TCP 三次握手成功 ≠ 104 通信建立。标准流程是：

  1. 主站（或子站）发起 TCP 连接到 2404 端口；
  2. 发送 STARTDT_ACT，对方回 STARTDT_CON，进入可传数据状态；
  3. 主站发总召唤 C_IC_NA_1，子站按点表回全数据；
  4. 之后变化数据主动上送、周期召唤、对时、链路测试。

链路能 ping 通但后台无数据，十有八九卡在第 2 步没发 STARTDT，或者 U 帧握手后被防火墙/NAT 丢弃。

流量与超时参数

参数 含义 常见默认
k 未被确认的 I 帧最大数量，达到即停发 12
w 收到多少个 I 帧后必须回 S 帧确认 8
t0 建立连接超时 30 s（部分实现取 10 s）
t1 发送/测试 APDU 的确认超时 15 s
t2 无数据发送时的确认超时（须 < t1） 10 s
t3 链路空闲多久发 TESTFR 测试帧 20 s

k/w 与 t0~t3 主子站两侧必须一致，否则会出现「通信时通时断、后台频繁报链路中断」。经过状态态防火墙或 NAT 的长连接，建议同时打开 TCP keepalive；空闲链路被防火墙静默丢弃，现象看起来像 104 规约故障，其实是网络问题。

常见类型标识与地址

方向 类型标识 用途
监视方向 M_SP_NA_1(1) / M_DP_NA_1(3) 单点 / 双点遥信
监视方向 M_ME_NA_1(9) / M_ME_NC_1(13) 归一化值 / 短浮点遥测
监视方向 M_IT_NA_1(15) 累计量（电度）
监视方向 M_SP_TB_1(30) / M_DP_TB_1(31) 带 CP56Time2a 时标的 SOE
控制方向 C_SC_NA_1(45) / C_DC_NA_1(46) 单点 / 双点遥控
控制方向 C_SE_NC_1(50) 遥调设点
控制方向 C_IC_NA_1(100) 总召唤
控制方向 C_CS_NA_1(103) 时钟同步
  • 四遥地址分段（2002 版常用口径）：遥信 0x0001 起、遥测 0x4001 起、遥控 0x6001 起，具体上界与公共地址、传送原因、信息体地址字节数（常见 2/2/3）由双方点表约定。
  • 传送原因要看懂：3 突发（变化上送）、20 响应总召唤、6/7/10 激活/激活确认/激活终止。遥控是「选择 → 返校 → 执行/撤销」，不是一条命令直接合闸。
  • CP56Time2a 是 7 字节时标，带毫秒与品质位；SOE 分辨率与全站对时精度直接相关。
  • 品质位（IV 无效 / NT 非当前 / SB 被取代 / BL 闭锁 / OV 溢出）别只当状态位跳过：数据看着有值但被标记 IV/NT 时，后台应显示为无效而不是照常参与计算。

四、103 与 Modbus：老站最耗时的两块

103（DL/T 667）

保护装置与站控层之间用 ASDU + FUN（功能类型）+ INF（信息序号） 定位信息，同一类信息在不同厂家装置上的 FUN/INF 定义并不统一，必须对着厂家规约说明书逐点解释。除了遥信、遥测，103 还承担定值区切换、扰动数据（故障录波）传输、总召唤等，调试时常见问题是只接了动作信号、没接扰动数据传输通道，事后调故障波形时才发现没数据。

串口侧要注意：RS-485 手拉手接线、两端 120 Ω 终端电阻、A/B 极性一致、波特率（常见 9600/19200）与校验位两侧一致；一个 485 口挂的装置数量受单位负载限制，别把十几台保护串成一条总线还指望轮询周期达标。

Modbus / DL/T 645

项 常见取值 / 坑
RTU 串口，CRC16 校验，从站地址 1~247
TCP 端口 502，MBAP 头，无 CRC
功能码 01 读线圈、02 读离散输入、03 读保持寄存器、04 读输入寄存器、06 写单寄存器、10(0x10) 写多寄存器
地址偏移 手册写「40001」，报文里偏移量往往是 0；3xxxx/4xxxx 与 0 基址混用是最常见的读错值原因
字节序 32 位浮点/长整型的 ABCD / BADC / CDAB / DCBA 四种组合，必须实测一组已知值确认
缩放系数 电表常传整数，需乘倍率（如 0.01、0.1）；倍率写错，读数差 10 倍或 100 倍
轮询 一条 485 总线上设备越多、超时越长，刷新越慢；分口、分波特率比硬堆从站地址有效

DL/T 645 的帧以 68H … 16H 包裹，地址域 6 字节 BCD、数据域按 +33H 处理、末尾校验和，常见 2400 bps。它和 Modbus 不是一回事，一块电表只走其中一种，接线前先确认表计规约和地址（表号），混接的表现是「有报文、无应答」。

五、IEC 61850：不是「更快的 104」

61850 的核心不是传输速度，而是面向对象建模 + 自描述，目标是取消手工点表：

  • 模型层次：LD（逻辑设备）→ LN（逻辑节点）→ DO（数据对象）→ DA（数据属性）。常见 LN：XCBR 断路器、CSWI 开关控制、MMXU 测量、PDIF 差动保护、PTOV 过电压、GGIO 通用 I/O。
  • SCL 文件族：ICD（装置能力描述）、IID（实例描述）、SCD（全站配置）、CID（装置实例配置）、SSD/SED（系统规格/交换描述）。工程交付时 SCD 与 CID 版本必须一致，装置换了固件要重新核对 ICD。
  • 三类服务：MMS（站控层客户/服务器，报告、控制、文件、定值，TCP/IP）、GOOSE（二层组播，EtherType 0x88B8，跳闸与联锁，毫秒级）、SV（IEC 61850-9-2 采样值，过程层）。
  • 报告控制块：BRCB / URCB、数据集、触发条件（数据变化 / 品质变化 / 周期 / 总召）、缓冲与断链补传，配置错了表现为「后台数据不刷新」。
  • 控制模式：直控与选控（SBO，先选择后执行），含返校与超时撤销；GOOSE 的 stNum/sqNum 用于判别重发与新事件。
  • 网络与对时：三层两网、A/B 双网或 HSR/PRP 冗余，交换机需支持 VLAN、QoS 优先级与组播管理（GOOSE 不打 IP 层，组播 flooding 会拖垮站控网）；对时用 SNTP / IRIG-B / IEEE 1588(PTP)，保护级 SOE 通常要求 IRIG-B 或 PTP。

别把 61850 当成 104 的升级版：104 是「点号 + 值」，61850 是「对象 + 服务」，改造站里两者长期共存，网关机做的就是模型与点表的互相翻译。

六、真正花时间的不是规约，是点表

同一套 103 规约，不同厂家对「遥信点号 0x01 代表什么」的定义可能不一样；104 更是完全靠点表约定。工程上必须逐点核对：后台显示的「1 号主变高压侧开关」是否真的对应那台开关。跳过这步，投运后就可能出现遥控合了 A 开关、后台却显示 B 开关变位这类严重问题。

一份能用的点表至少包含：

字段 说明
点号 / 信息体地址 与规约报文一一对应
信号名称 中文全称 + 一次设备编号，不用简称
类型 遥信（单点/双点、COS/SOE）、遥测、遥控、遥调、电度
系数与单位 遥测倍率、工程量程、死区、越限告警阈值
品质与极性 常开/常闭、取反、品质位处理方式
源端 哪台装置、哪个端口、哪块端子
版本与变更记录 变更日期、变更人、双人复核签字

传动试验是唯一可靠验证：遥信逐点短接模拟、遥测加标准源/标准表比对、遥控逐点带一次设备实际传动（或至少到出口压板）、遥调设点验证。做传动前把遥控出口压板退出、做好安全措施，别在调试台上「顺手合一次」。

配套还要核：后台与调度两侧点表版本一致、SOE 时标一致、对时源正常、通信管理机断链缓存与补传、遥控返校超时与闭锁逻辑、双机切换时数据不丢。

七、通信管理机 / 远动机配置清单

  1. 串口数量与类型（RS-485/232、光电转换）、网口数量按实际接入设备清单配，不是按新设备规约配。
  2. 规约库清单逐项确认：每种规约的版本、波特率、校验、从站地址、超时与重试次数。
  3. 双机冗余：主备切换时间、切换时调度侧链路是否重连、数据是否补传。
  4. 对时：站内外时钟源、对时周期、装置对时是否生效（看时标而非看配置）。
  5. 遥信防抖时间按装置与规范设定（常见几十毫秒量级），太短易误报、太长漏 SOE。
  6. 遥测死区、越限阈值、上送周期，避免把调度通道刷爆。
  7. 断链缓存：网络中断期间的变位与 SOE 要能缓存补传，而不是恢复后只送当前值。
  8. 安全防护：按电力监控系统安全防护要求做「安全分区、网络专用、横向隔离、纵向防护」，远动通道的纵向加密、边界防火墙策略、账号与日志审计一并验收，别把调试用的直连通道留在生产网上。

九、选型与交付速记

交付资料：规约说明书、点表（带版本与签字）、通信网络拓扑与 IP 表、交换机配置备份、SCD/CID 文件、传动试验记录、对时精度记录、抓包与联动测试记录、安全防护策略清单。规约本身不复杂，复杂的是把每一位的含义和现场一次设备对上，这部分省不得。

柜内二次接线、通信线与动力线分离、屏蔽接地等施工细节，可对照低压柜型区别速查的工艺验收章节与4-20mA 与 0-10V 选型速查。
